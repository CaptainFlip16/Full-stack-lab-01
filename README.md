# Front-End Web Development Projects & Templates

A collection of responsive web pages and layout components built using HTML5, CSS3, and Bootstrap 5. This repository features single-page projects ranging from a personal portfolio to a documentation portal UI and responsive card grids.

---

## 📁 Project Breakdown

### 1. Personal Portfolio Website
A foundational portfolio landing page designed to showcase personal background, academic history, and technical skills.
* **Key Features:** Header with title/role details, top navigation bar with smooth section scrolling, about section with personal info table, education history breakdown, skills list, multi-input contact form, and external social media links.
* **Technologies:** HTML5, Bootstrap 5, Custom CSS (`style.css`).

### 2. DevDesk – Knowledge Base UI
A SaaS-inspired documentation and support portal interface designed for clean content presentation.
* **Key Features:** Collapsible header navbar with category dropdowns, high-impact hero search section, popular articles grid featuring upvote metrics, interactive category cards with Bootstrap icons, and mobile menu toggles.
* **Technologies:** HTML5, Bootstrap 5 (CSS & JS Bundle), Bootstrap Icons, Custom CSS (`style2.css`).

### 3. Amazing Animals – Responsive Card Grid
A clean, card-based layout demonstrating Bootstrap's flexbox grid utilities and responsive breakpoints.
* **Key Features:** Centered page container, dynamic 3-column layout that gracefully stacks on mobile screens, shadow-card styling with consistent height alignment, Unsplash image integration, and distinct color-coded call-to-action buttons.
* **Technologies:** HTML5, Bootstrap 5 CSS layout and components.
